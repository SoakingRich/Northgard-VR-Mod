# NorthgardVR UI layout v5: HUD pieces cut from the UI image and placed around the table.
# The game re-reads this file within a second of it changing.
#
# name   anchor   x  y  w  h   px py pz   yaw pitch   width_m
#
# anchor:
#   @win:<classes>  the rect of the game's own HUD window(s), read live from the game
#                   (follows resolution, UI scale, clan, language, selection).
#                   Comma-separated class names; a trailing * matches a prefix.
#                   Several windows -> their union. Exact names are matched before
#                   wildcards, and each window goes to one panel only.
#   @rest           the largest other visible window (Lore, pause, dialogs, ...); a second @rest line takes the next largest.
#   @win:tip        the hover tooltip; it pops up just above where the laser meets a panel.
#   lt/ct/rt/lb/...  a fixed rect (x y w h, UI px) measured from that corner of the UI image.
# For @win/@rest panels x y h are unused (for @win with h > 0, x y w h crop that part of the
# window, for full-screen windows like Pause), w is a nominal width in UI px and width_m the
# metres it gets (sets the scale), and p is the panel's BOTTOM centre.
# p = position in table space, metres: x right, y up, z towards you (for a 0.75 m table;
#   scaled with the table size). pitch -90 = lying flat.
#
# claim <classes>: windows that no panel shows (and @rest leaves out).
#
# Row: lines ending in "row" get fixed slots side by side (file order, left to right), centred
# on the "@row" line (p = bottom centre, yaw, pitch; width_m = gap in metres). Each slot is its
# width_m wide and stays put whether the panel is shown or not; a wider panel shrinks to fit.
# "rowup" stacks a panel on top of the row member before it.
